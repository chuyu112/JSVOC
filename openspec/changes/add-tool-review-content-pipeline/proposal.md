# Proposal: AI 短视频解决方案内容生产流程

## 背景

JPASP 已接入 image-2（生图）和 seedance（生视频），具备从账号定位、执行计划、选题、文案、生图、生视频到内容发布的全链路能力。

对标账号「仙女龙AI」通过强调底层工具（image-2 + seedance）吸引工具学习者，但 JPASP 的目标用户是**终端商家和创作者**——他们不关心用了什么模型，只关心"能不能帮我解决问题"。

因此，JPASP 的内容策略必须与工具博主路线彻底区分：
- **不说工具名**，不说技术细节
- **只说生意**，说成本、说效率、说效果
- **展示输入→输出**，不展示中间操作过程

## 目标

为 JPASP 增加一套「AI 短视频解决方案」内容生产流程规范，面向中小商家、本地生活店主、电商卖家、内容创作者等终端用户，强调"一站式解决方案"而非"工具组合教程"。

规范包括：

1. **账号定位策略模板** — 短视频解决方案专家的人设、栏目、信任背书
2. **内容漏斗模型** — 行业痛点 → 效果展示 → 解决方案的三层结构
3. **选题生成模板** — 基于行业场景和生意痛点的选题公式
4. **脚本结构模板** — 三种核心视频类型的文案框架（痛点型/展示型/对比型）
5. **转化路径设计** — 从内容曝光到平台试用的低门槛链路
6. **平台适配规则** — 各平台的差异化表达（抖音/视频号/小红书/快手）

## 非目标

- 不展示底层模型或工具操作过程
- 不面向"想学习 AI 工具"的学生群体
- 不替代现有通用账号包装模块，而是作为"解决方案型"行业模板

## 预期收益

- 使用 JPASP 的商家可以直接套用这套模板生成账号策略和选题
- 内容团队可以按此规范批量生产"解决方案导向"的短视频
- 建立 JPASP 在终端用户心中的"短视频内容工厂"定位
