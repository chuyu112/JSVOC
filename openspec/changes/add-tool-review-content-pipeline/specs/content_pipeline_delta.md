# Delta Spec: AI 短视频解决方案内容生产流程

## 1. 账号定位策略模板

### 1.1 核心定位公式

```
[解决方案身份] + [目标行业/人群] + [核心价值] = 账号定位
```

**示例（JSVOC 通用）：**
- 解决方案身份：AI 短视频内容工厂
- 目标行业：中小商家、电商卖家、本地生活店主
- 核心价值：从策划到发布，一站式搞定
- 账号定位：不用请团队，AI 帮你一个月做出 30 条短视频

**示例（JSVOC 翡翠行业）：**
- 解决方案身份：翡翠短视频内容工厂
- 目标行业：四会/平洲/瑞丽翡翠小老板、翡翠货主
- 核心价值：不用懂短视频，AI 帮你做出能卖货的翡翠抖音号
- 账号定位：翡翠老板做抖音，不用请团队，AI 3 分钟出 30 天方案

**禁忌：**
- ❌ "教你用 image-2 生图"
- ❌ "seedance 2.0 实测"
- ❌ "AI 工具测评"
- ✅ "3 分钟生成一周短视频"
- ✅ "餐饮老板这样做抖音，客单价翻倍"
- ✅ "一个人就是一支短视频团队"

### 1.2 人设包装要素

| 要素 | 要求 | 示例 |
|------|------|------|
| 头像 | 品牌 LOGO 或真人专业形象 | JSVOC 品牌标识 |
| 昵称 | 品牌名 或 解决方案属性 | JSVOC、AI内容工厂 |
| 简介 | 一句话核心价值 + 试用入口 | "一站式短视频生成平台，3分钟出方案，点击试用" |
| 背景图 | 产品界面或客户成果展示 | 后台操作界面 / 客户案例数据 |
| 信任背书 | 服务客户数、生成内容量、覆盖行业 | "已服务 1000+ 商家，生成 50000+ 条短视频" |

### 1.3 内容栏目设计

```yaml
columns:
  - name: 行业案例拆解
    frequency: 每周 2 条
    purpose: 引流 + 信任 — 展示 JSVOC 给某个行业做的全套方案
    format: "给【XX行业】做短视频，AI 生成的方案全过程"

  - name: 前后对比
    frequency: 每周 1 条
    purpose: 信任 — 传统方式 vs AI 方式的成本/效率/效果对比
    format: "请代运营 VS AI 平台，同样 30 天，差距有多大"

  - name: 一键生成演示

    format: "客户【XX店】用 JSVOC 3 个月，抖音来客增长 300%"
```

## 2. 内容漏斗模型

### 2.1 三层漏斗结构

```
┌─────────────────────────────────────────────────────────────┐
│  第一层：行业痛点（泛流量）                                   │
│  目标：让目标行业的商家觉得"说的就是我"                        │
│  选题：具体行业 + 具体成本/痛点 + 问号/惊叹                    │
│  标题关键词：多少钱、怎么做的、太难了、终于、居然               │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  第二层：效果展示（精准流量）                                 │
│  目标：让用户相信"这个真能做出效果"                            │
│  选题：输入 → 输出展示、全流程演示、客户成果                   │
│  标题关键词：全过程、看效果、生成的、自动的、一站式             │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  第三层：解决方案（转化流量）                                 │
│  目标：降低最后一步决策阻力，直接试用                          │
│  选题：成本对比、免费试用、限时福利、行业模板                  │
│  标题关键词：免费试、500/月、前100名、点击即用                 │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 漏斗选题配比

| 层级 | 占比 | 发布节奏 | 目标 |
|------|------|---------|------|
| 行业痛点 | 35% | 每周 2-3 条 | 破圈、让目标行业用户刷到 |
| 效果展示 | 40% | 每周 2-3 条 | 建立信任、展示产品能力 |
| 解决方案 | 25% | 每周 1-2 条 | 注册试用、付费转化 |

**注意：** 效果展示占比最高，因为 JSVOC 的核心竞争力就是"能做出效果"。

## 3. 选题生成模板

### 3.1 选题公式

```
选题 = [目标行业/场景] + [痛点/成本/效果] + [解决方案暗示]
```

### 3.2 四种核心选题类型

**类型 A：行业痛点型（引流层）**
- 公式：`具体行业 + 具体痛点 + 情绪共鸣`
- 示例：
  - "餐饮店拍抖音，每个月要花多少钱？"
  - "翡翠店做短视频，最大的坑不是拍摄，是文案"
  - "为什么你拍的短视频没人看？90%的商家都踩了这个坑"
- 关键词：多少钱、坑、为什么、没人看、太难了

**类型 B：效果展示型（信任层）**
- 公式：`输入 + 输出 + 效果惊叹`
- 示例：
  - "输入'四会翡翠手镯'，AI 生成了 30 天短视频方案"
  - "给这个口红品牌做了 50 条带货脚本，全程展示"
  - "从账号定位到发布，AI 一站式生成的全过程"
- 关键词：生成、自动、一站式、全过程、看效果

**类型 C：成本对比型（转化层）**
- 公式：`传统成本 + AI成本 + 差距震撼`
- 示例：
  - "请代运营 5000/月，用 AI 平台 500/月，效果对比"
  - "招一个短视频运营 8000/月，这个平台 300/月"
  - "拍一条短视频，传统方式 2 天，AI 方式 10 分钟"
- 关键词：对比、差距、省钱、划算、替代

**类型 D：效率惊叹型（引流+信任层）**
- 公式：`时间数字 + 产出数字 + 不可思议`
- 示例：
  - "3 分钟生成一周的短视频内容"
  - "一个人一天做出 30 条口播文案"
  - "10 分钟搞定一个月的短视频策划"
- 关键词：分钟、一天、自动、批量、搞定

## 4. 脚本结构模板

### 4.1 类型 A：行业痛点型（引流层）

```yaml
structure:
  duration: 30-60 秒
  sections:
    - name: 痛点放大（0-5 秒）
      formula: 具体数字/场景 + 情绪钩子
      example: "餐饮店做抖音，一个月要花 2 万块"
      requirement: 必须出现具体行业 + 具体成本数字

    - name: 拆解成本（5-15 秒）
      formula: 逐项拆解 + 隐形痛点
      example: "文案 3000，拍摄 5000，剪辑 4000，投流另算...还没算试错成本"
      requirement: 让用户觉得"原来这么贵"

    - name: 转折引方案（15-25 秒）
      formula: "其实不用这么麻烦" + 解决方案暗示
      example: "其实根本不用请这么多人，AI 现在能一站式做完"
      requirement: 不透露具体工具，只说"AI 平台/一站式"

    - name: 效果预览（25-40 秒）
      formula: 展示产出物（文案/图片/视频片段）
      example: "输入你的店名和主营，3 分钟后，30 天方案 + 口播文案 + 分镜图全出来了"
      requirement: 必须出现 JSVOC 界面或产出的真实内容

    - name: 结尾引导（40-60 秒）
      formula: 降低门槛 + 明确行动
      example: "想知道你的行业做短视频要多少钱？评论区留下你的行业，我帮你算"
      requirement: 用互动或免费试用做钩子，不硬推付费
```

### 4.2 类型 B：效果展示型（信任层）

```yaml
structure:
  duration: 45-90 秒
  sections:
    - name: 结果前置（0-3 秒）
      formula: 直接展示最震撼的产出物
      example: "这就是 AI 生成的 30 天短视频方案"

    - name: 输入展示（3-10 秒）
      formula: 展示输入的信息有多简单
      example: "我只输入了'四会翡翠手镯，目标客户是 30-50 岁女性'"
      requirement: 强调"输入很少，输出很多"

    - name: 输出展示（10-40 秒）
      formula: 逐项展示产出物
      example: "这是账号定位，这是 30 天选题表，这是口播文案，这是分镜图..."
      requirement: 必须展示 JSVOC 的真实界面和真实输出

    - name: 效果强化（40-60 秒）
      formula: 客户反应 / 数据结果 / 前后对比
      example: "客户说，以前请团队一个月 2 万，现在 500 块搞定"
      requirement: 用第三方视角（客户/数据）增强可信度

    - name: 结尾引导（60-75 秒）
      formula: 试用门槛极低 + 紧迫感
      example: "这个案例的完整方案我放在评论区了，注册就能直接套用"

    - name: 互动设计（75-90 秒）
      formula: 评论区引导 + 私信钩子
      example: "想知道你的行业能生成什么？评论区打你的行业，下期出案例"
```

### 4.3 类型 C：成本对比型（转化层）

```yaml
structure:
  duration: 30-60 秒
  sections:
    - name: 成本焦虑（0-5 秒）
      formula: 直击商家最敏感的数字
      example: "做短视频，你最关心的就是：多少钱？"

    - name: 传统方案报价（5-15 秒）
      formula: 逐项列明 + 总价震撼
      example: "代运营 5000/月，文案 3000，拍摄 5000，剪辑 3000，一个月下来 16000"
      requirement: 数字必须真实可信，不夸大

    - name: AI 方案报价（15-25 秒）
      formula: 总价的强烈对比
      example: "用 AI 平台，策划 + 文案 + 生图 + 生视频，一个月 500"
      requirement: 必须说明包含什么服务，避免"便宜没好货"印象

    - name: 效果承诺（25-40 秒）
      formula: 效果不输传统方案 + 证据
      example: "效果怎么样？这是同一家店，左边是代运营做的，右边是 AI 做的"
      requirement: 必须展示真实对比，不能虚构

    - name: 行动号召（40-60 秒）
      formula: 限时/限量 + 零风险承诺
      example: "前 100 名注册送 7 天免费试用，不满意不用付钱"
      requirement: 必须包含明确的转化路径（链接/评论区/私信）
```

### 4.5 口播文案风格指南（Khazix 风格）

> 本指南提取自 `khazix-writer` skill 的"活人感"写作规则，适配 30-60 秒短视频口播文案。  
> 核心原则：**"有见识的普通人在认真聊一件打动他的事。"**

#### 风格定位

- **像真人聊天**，不像念稿。句子时长时短，用逗号制造停顿感
- **敢下判断，有明确好恶**，但姿态是"我被打动了"而不是"我来教你"
- **自嘲和承认不足**，降低读者防御心（"说实话我也不确定""我自己也还在摸索"）
- **从具体事件切入**，绝不宏大叙事。禁止"在当今...的时代""随着...的发展"

#### 禁用词清单（口播版）

以下词汇在口播文案中绝对禁止出现：

| 禁用词 | 替换说法 |
|--------|---------|
| 说白了 | 坦率的讲、其实就是 |
| 意味着什么 / 这意味着 | 那结果会怎样呢、所以呢 |
| 本质上 | 说到底、其实 |
| 换句话说 | 你想想看、也就是说 |
| 不可否认 | 直接删掉，换正面陈述 |
| 综上所述 / 总的来说 | 具体的回扣句 |
| 首先...其次...最后 | 自然的转场词 |
| 值得注意的是 / 不难发现 | 删掉，直接说 |
| AI / 人工智能 / 大模型 / 生成式 / 算法 | 见 9B.2 术语替换表 |

#### 禁用标点（口播版）

口播文案中：
- 不用冒号"："，用逗号或停顿代替
- 不用破折号"——"，用逗号或句号代替
- 不用双引号""""，需要引用时用「」或去掉引号
- 不用分号"；"

#### 推荐口语化表达（口播高频）

**转场和过渡：**
坦率的讲、说真的、怎么说呢、其实吧、你想想看、我跟你说、回到这块、这块需要注意一下

**表达判断：**
我有时候觉得、这话听着有点刺耳但、我自己的感受是、我始终坚信

**承认和自嘲：**
说实话我也不确定、我自己也还在摸索、可能有些想法还不成熟、这个事儿我也踩过坑

**情绪表达：**
我当时就愣住了、想想就觉得兴奋、我真的被震撼到了、太离谱了、太特么厉害了、给我一下子整不会了

**拉近距离：**
很多朋友可能不知道、可能有小伙伴纳闷、你如果关注这个领域的话、大家也都知道

**口头禅：**
这玩意、不是哥们、真的就是一声叹息、太牛逼了、比较骚的事

> 注意：不是每句话都塞，而是在转场、表达观点、拉近距离时自然用上去。

#### 节奏控制（30-60 秒口播专用）

**短句法则：**
- 一句话不超过 15 个字最好，最长不超过 25 个字
- 关键信息单独成句，制造停顿和重量感
- 例："黑暗森林。""大时代啊，朋友们。""尼玛。"

**疑问句刹车：**
- 在关键节点用问句让读者停一秒："为啥会这样呢？"
- 共鸣式问句："听着很难理解对吧？""你也是这样吗？"

**扣主线句：**
- 每偏离主线 2-3 句后，用一句拉回主题
- 例："说到这个，还是回到成本这块""扯远了，说回你的店"

#### 口播文案质检清单（简化版）

写完口播稿后，逐条检查：

**L1 硬性规则**
- [ ] 禁用词零命中
- [ ] 禁用标点零命中
- [ ] 没有出现"AI""大模型"等技术术语
- [ ] 没有出现"首先/其次/最后"

**L2 风格一致性**
- [ ] 开头是从具体事件切入，不是宏大叙事
- [ ] 有至少 3 处口语化表达
- [ ] 有至少 1 处自嘲或承认不足
- [ ] 长短句交替，没有连续 3 句以上句式相近

**L3 活人感终审**
- [ ] 读一遍，感觉像是真人在说话，不是在念稿
- [ ] 情绪表达是体感记忆（"我当时就愣住了"），不是知识性描述（"我感到非常震撼"）
- [ ] 姿态是"一个有见识的普通人在聊一件打动他的事"，不是"导师在教学生"

## 5. 转化路径设计

### 5.1 漏斗转化链路

```
抖音视频曝光
    ↓ 被行业痛点/效果展示吸引
点击头像/主页
    ↓ 看到简介中的试用入口
JSVOC 注册页 / 免费试用页
    ↓ 输入行业信息，生成第一条方案
体验产品 → 看到效果
    ↓ 满意 → 付费订阅 / 不满意 → 流失
付费用户 / 长期留存
```

### 5.2 各触点转化设计

| 触点 | 转化动作 | 具体设计 |
|------|---------|---------|
| 视频评论区 | 置顶评论引导 | "想知道你的行业做短视频要多少钱？评论区留下行业，我帮你算" |
| 个人简介 | 试用入口 | "一站式短视频生成平台，点击试用" + 官网链接 |
| 粉丝群 | 案例库引流 | 进群领"10 个行业短视频方案模板" |
| 私信自动回复 | 注册引导 | "点击链接，输入你的行业，3 分钟出方案" |
| 置顶视频 | 能力展示 | 三条置顶 = 行业痛点 / 效果展示 / 成本对比，新用户一进主页就看到完整价值 |

### 5.3 转化话术模板

**轻引导（行业痛点视频）：**
- "想知道你的行业做短视频要多少钱？评论区打你的行业"
- "这个案例的完整方案，私信'方案'发你"
- "下期出你的行业案例，评论区报名"

**中引导（效果展示视频）：**
- "这个效果就是用我们平台生成的，注册免费试"

### 9.2 翡翠商家痛点清单

**成本痛点：**
- 请代运营一个月 5000-15000，效果还不确定
- 招一个短视频运营，工资 6000+，还要配设备
- 找人拍一条视频 500-1000，一个月拍不起几条

**能力痛点：**
- 不知道怎么定位账号，发什么内容
- 不会写口播文案，对着镜头说不出话
- 不懂抖音算法，发了没人看

- 翡翠行业本身就缺信任，拍短视频怕说错话被同行笑话
- 怕露脸，怕客户看到自己在拍抖音觉得不专业
- 担心花了时间做抖音，最后没效果

**内容痛点：**
- 不知道翡翠账号该发什么（不能只发产品图）
- 同行都在拍什么，不知道怎么差异化
- 拍的产品视频像广告，没人看

| 算法 | 推荐机制（尽量少提） |
| 提示词 / prompt | 输入信息 / 告诉它 |
| 文生图 / 图生视频 | 自动出图 / 自动转视频 |
| 接入 / API | 已开通 / 已备好 |
| 模型 / model | 功能 / 能力 |
| 算力 / 推理 | 处理速度 / 生成速度 |

**正确的话术示例：**
- ❌ "用 AI 生成口播文案" → ✅ "输入你的店名，自动给你写好口播稿"
- ❌ "接入了大模型" → ✅ "平台已经帮你准备好了"
- ❌ "文生图功能" → ✅ "输入描述，自动出图"
- ❌ "提示词工程" → ✅ "告诉它你卖什么"

### 9B.3 通用痛点清单（跨行业）

**成本痛点：**
- 请代运营一个月 3000-15000，不知道钱花哪了
- 招一个员工做抖音，工资 5000+，还要教、还要管
- 找人拍一条视频 300-1000，一个月拍不起几条

**能力痛点：**
- 不知道怎么写文案，对着手机说不出话
- 不会拍、不会剪、不会加字幕
- 不知道发什么内容，发了也没人看

**时间痛点：**
- 白天要看店、要接待客户，晚上累得要死，没精力拍视频
- 拍一条视频要半天，三天打鱼两天晒网

**信任痛点：**
- 之前找过代运营，钱花了没效果，再也不信了
- 担心被骗，担心平台跑路
- 怕拍了视频被同行笑话

### 9B.4 通用选题库（跨行业）

**行业痛点型：**
1. "小老板做抖音，一个月到底要花多少钱？"
2. "请代运营 3 个月，为什么一条爆款都没出？"
3. "为什么你发的视频没人看？不是生意不好，是方法错了"
4. "小老板做抖音最大的坑：把抖音当朋友圈发"
5. "不懂短视频的小老板，怎么开始第一条视频？"

**效果展示型：**
6. "输入店名和主营，3 分钟后 30 天方案出来了"
7. "给这个餐饮店做的 30 条口播文案，全程展示"
8. "从'我是谁'到'发布'，一站式做完的账号"
9. "这条口播文案是自动写的，你看出来了吗？"
10. "输入'火锅店，主打毛肚'，看它给你出什么内容"

**成本对比型：**
11. "请员工做抖音 6000/月，用这个平台 500/月"
12. "拍一条视频，传统方式 2 天，这里 10 分钟"
13. "小老板做抖音，省钱和效果好不能同时有？"

**效率惊叹型：**
14. "3 分钟生成一周的短视频内容"
15. "一个人一天做出 30 条口播文案"
16. "10 分钟搞定一个月账号的策划+文案+分镜"

### 9B.5 通用脚本示例（不说 AI 版）

**示例 A：行业痛点型《小老板做抖音，一个月到底要花多少钱？》**

```
[0-5秒] 痛点放大
"小老板做抖音，一个月到底要花多少钱？"
"今天帮你算一笔账。"

[5-15秒] 拆解成本
"请个员工专门做，工资 5000，设备 3000，这是最基本的。"
"还没算你学拍摄、学剪辑、想文案的时间。"
"一个月下来，少说 1 万。"

[15-25秒] 转折引方案
"其实现在不用这么麻烦了。"
"有个平台，你输入店名和卖什么，它自动帮你出方案、写文案、做分镜。"

[25-40秒] 效果预览
"你看：输入'火锅店，毛肚是招牌，人均 80'。"
"3 分钟后，账号定位出来了：'专吃毛肚的火锅店，人均不到 80'。"
"30 天选题出来了，口播文案出来了，分镜图也出来了。"
"这条文案：'来我们家吃火锅，毛肚不脆不要钱...'"

[40-60秒] 结尾引导
"想知道你的店做抖音要多少钱？"
"评论区留下你的行业和店名，我帮你算。"
```

**示例 B：效果展示型《输入店名和主营，3 分钟后 30 天方案出来了》**

```
[0-3秒] 结果前置
"这就是给一个美甲店做的 30 天短视频方案。"

[3-10秒] 输入展示
"我只输入了两句话：'美甲店，主打日式美甲， target 20-35 岁女生'。"

[10-35秒] 输出展示
"账号定位：'做了 8 年美甲，只做法式不踩雷'。"
"30 天选题：第 1 天'显白美甲颜色怎么选'，第 2 天'短指甲也能做的 5 款美甲'..."
"口播文案：'为什么你做的美甲总是翻车？不是手的问题，是颜色没选对...'"
"分镜图：开场怎么拍、产品怎么拍、字幕放哪，全标好了。"

[35-50秒] 效果强化
"这个方案给一个美甲店用了，她以前一个月发 5 条，现在一天发 2 条。"
"她说，以前想文案要想 1 小时，现在照着念就行。"

[50-65秒] 结尾引导
"想要这个方案模板的，评论区扣你的行业，私信发你。"
"或者点击主页链接，输入你的店名，3 分钟出同款。"
```

### 9B.7 通用平台适配

**抖音：**
- 强调"小老板""省钱""一个人也能做"
- 用各行各业真实场景做背景（店面、档口、厨房）

**视频号：**

- 结合公众号文章做深度案例

**小红书：**
- 图文笔记展示"30 天选题表""口播文案合集"
- 封面用行业场景图+大字号文字
- 标签：#开店 #创业 #短视频运营 #小老板 #省钱

**快手：**
- 直接说价格，"一条视频不到 20 块"
- 强调"小本生意也能做抖音"
- 用店面实拍画面，增强真实感

### 9B.8 与翡翠模板的区别

| 维度 | 翡翠模板（第一步） | 通用小商家模板（第二步） |
|------|-------------------|------------------------|
| 目标用户 | 翡翠行业（特定） | 各行各业（泛） |
| 行业深度 | 深（地域、术语、行规） | 浅（通用痛点，跨行业共鸣） |
| 话术 | 可用"翡翠""四会"等行业词 | 只用通用词，任何行业都懂 |
| 内容方向 | 行业垂直 | 跨行业横向 |
| 扩展性 | 低（只适合翡翠） | 高（餐饮/服装/美业/零售通用） |

## 10. 扩展行业模板指南

### 10.1 模板结构

每个行业模板应包含：
1. 目标人群画像
2. 行业痛点清单（成本/能力/信任/内容）
3. 行业选题库（痛点型/展示型/对比型/效率型）
4. 行业脚本示例（3 个完整脚本）
5. 行业转化话术
6. 行业平台适配要点
7. 行业 30 天执行计划（简化版）

### 10.2 首批扩展行业建议

| 优先级 | 行业 | 原因 |
|--------|------|------|
| P0 | 翡翠珠宝 | 已有模板，目标用户明确 |
| P1 | 餐饮/本地生活 | 抖音本地生活流量大，商家痛点强 |
| P1 | 电商/带货 | 短视频直接关联销售转化 |
| P2 | 美业/医美 | 高客单价，内容门槛高，AI价值大 |
| P2 | 教育培训 | 口播内容为主，JSVOC文案能力强 |
| P3 | 房产/汽车 | 决策周期长，需要信任建设 |

### 10.3 Prompt 集成方式

在选题生成和文案生成模块中，增加`industry_template`参数：
- 当用户选择"翡翠"行业时，注入 9.1-9.7 节的全部内容
- 当用户选择其他行业时，使用通用模板 + 行业关键词替换
- 行业模板中的`target_industry`、`pain_points`、`example_topics`直接注入 prompt
