## 阶段一：规范定义

- [ ] 1.1 定义账号定位策略模板（人设、栏目、信任背书、转化路径）
- [ ] 1.2 定义内容漏斗模型（引流层/信任层/转化层的三层选题结构）
- [ ] 1.3 定义选题生成模板（热点工具组合公式 + 选题库）

- [ ] 1.5 定义转化路径设计（从测评到注册的引导链路）
- [ ] 1.6 定义平台适配规则（抖音/视频号/小红书/快手的差异化表达）
