# 用户指南

## 1. 创建项目

1. 打开前端：

   ```text
   http://127.0.0.1:5173
   ```

2. 进入“项目档案”。
3. 点击“新建项目”。
4. 填写项目档案：
   - 项目名称
   - 行业
   - 细分行业
   - 产品
   - 个人简介
   - 目标客户
   - 发布平台
   - 当前阶段
5. 点击保存。

示例项目：

- 行业：珠宝
- 产品：翡翠
- 个人简介：在四会卖翡翠多年，为人靠谱
- 目标客户：喜欢翡翠，想买翡翠的人
- 平台：抖音、视频号、快手、小红书

## 2. 生成账号包装

1. 进入项目详情页。
2. 点击“账号包装”。
3. 点击“生成账号包装”。
4. 页面会展示：
   - 账号核心定位
   - 人设包装
   - 目标用户画像
   - 账号名称建议
   - 各平台简介
   - 内容栏目
   - 信任设计
   - 转化路径
   - 平台策略
5. 可点击复制结果。

账号包装生成后，系统会保存账号策略上下文，供后续执行计划、选题和文案使用。

## 3. 生成执行计划

1. 进入项目详情页。
2. 点击“执行计划”。
3. 选择：
   - 执行周期
   - 每天可投入时间
4. 点击“生成执行计划”。
5. 页面会展示：
   - 周期
   - 每周计划
   - 每日计划
   - 每日任务
   - 每日选题方向
   - 拍摄任务
   - 复盘指标
6. 可点击复制结果。

MVP 默认支持 30 天执行计划。

## 4. 生成选题

1. 进入项目详情页。
2. 点击“选题生成”。
3. 选择：
   - 平台
   - 内容目标
   - 选题数量
4. 点击“生成选题”。
5. 页面会展示每个选题：
   - 标题
   - 内容类型
   - 平台
   - 目标
   - 用户痛点
   - 开头钩子
   - 拍摄建议
   - 转化方式
   - 评分
6. 可复制单个选题或复制全部选题。

生成的选题会保存到 `topics`，后续文案生成必须基于已保存选题。

## 5. 生成文案

1. 进入项目详情页。
2. 点击“选题生成”。
3. 在某个已保存选题卡片中点击“生成文案”。
4. 进入文案生成页面。
5. 页面会展示当前选题信息。
6. 选择：
   - 写法
   - 平台
   - 视频时长
   - 内容目标
7. 点击“生成文案”。
8. 页面会展示：
   - 标题
   - 开头钩子
   - 正文口播
   - 镜头建议
   - 字幕重点
   - 结尾转化
   - 评论区引导
   - 私信引导
9. 可复制文案或复制完整 JSON。

支持的写法：

- 聊观点
- 讲故事
- 列清单
- 做对比
- 拆案例
- 讲误区
- 提问题
- 反常识
- 场景代入
- 客户问答

## 6. 查看生成历史

### 查看全部历史

访问：

```text
/history
```

页面支持筛选：

- 项目 ID
- 模块类型

模块类型包括：

- 账号包装
- 执行计划
- 选题生成
- 文案生成

### 查看项目历史

从项目详情页点击“生成历史”，或访问：

```text
/projects/:id/history
```

### 查看记录详情

在历史列表中展开记录，可查看：

- `input_data`
- `output_data`
- `token_usage`
- `latency_ms`

支持复制：

- input_data
- output_data
- 完整 JSON
