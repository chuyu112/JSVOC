# JPASP 营销内容目录

本目录存放 JPASP 市场推广相关的所有内容资产。

## 项目三层结构

JPASP 项目实际包含三个层次，本目录属于**内容层**：

| 层次 | 路径 | 说明 |
|------|------|------|
| **代码层** | `frontend/` `backend/` | JPASP 系统的 Vue 3 + FastAPI 实现 |
| **规范层** | `openspec/` | 定义内容生产流程、系统架构规范 |
| **内容层** | `marketing/` | 短视频选题、脚本、拍摄计划、复盘数据 |

三层完全独立，互不影响。

## 目录说明

- `topics/` — 选题库（候选选题、评分、排序）
- `scripts/` — 逐字稿/口播文案
- `shots/` — 分镜脚本、拍摄素材、成片
- `retro/` — 发布数据、复盘分析
